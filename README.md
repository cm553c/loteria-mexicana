# 🇲🇽 El Gritón — Lotería Mexicana Tradicional

👉 **Jugar ahora en vivo (Celular / PC / TV):** https://cm553c.github.io/loteria-mexicana/

Aplicación web progresiva (PWA) para **cantar las 54 cartas de la Lotería Mexicana tradicional** con voz en español, **216 dichos aleatorios** (4 versos distintos por cada carta que se alternan entre corridas) y **Mesa de Cartas Cantadas** en vivo para jugar con tablas físicas impresas.

## ✨ Características
- **Las 54 cartas tradicionales Don Clemente** (`cartas/1.jpg` a `cartas/54.jpg`).
- **4 dichos tradicionales por carta** que se eligen al azar sin repetir el de la corrida anterior.
- **Mesa de Cartas Cantadas en vivo**: Muestra todas las cartas que ya salieron, con filtro por orden de salida o por número (1 al 54) y buscador instantáneo.
- **Modo Automático inteligente** y **Modo Manual**.
- **Lista para celulares (PWA + Wake Lock)**: No apaga la pantalla del celular mientras El Gritón está cantando.
